# Xiaomi SW-106T-A_XM V0.2.6

Final LED iteration for the Xiaomi SW-106T-A (RTL8372N, 4 x 2.5G RJ45 +
2 x SFP+).

## Firmware

`SW-106T-A_XM-V0.2.6.bin`

- Size: 524288 bytes (512 KB)
- SHA256: `99e948a512654c7692e4f30c3dcaff1a46d5da31355307502d704ec3bc4d7d2f`
- No 4 MB padding

## LED behaviour

| State | LED |
|---|---|
| No link | all off |
| Port 1 | 1 green blink |
| Port 2 | 2 green blink |
| Port 3 | 3 green blink |
| Port 4 | 4 amber blink |
| SFP5 | 5 blue blink |
| SFP6 | 6 blue blink |

Port 4 is amber on this unit; that is the measured behaviour, not a fault.

Register settings:

```text
LED_PORT_SET_SEL     = 0x00030ac0
LED_GLB_IO_EN        = 0xffffffff
LED_GLB_ACTIVE       = 0x3fffffff
led_mux              custom, pad based
```

## Notes

- The default build has no `hostname` in the startup config, so the UI shows
  `RTLPlayground-XXXXXX` in the top-left corner. Set a hostname, or build with
  a config that contains one, to show a custom name.
- Web firmware update preserves the configuration sector.
- A configured image needs `factory-reset`, restore-defaults, or a programmer
  full-image write.
