# Iteration V0.1.2_NOLED — network baseline

## Goal

Produce a bootable, manageable RTLPlayground image for the Xiaomi SW-106T-A
before touching LED behaviour.

## Result

- Boots on hardware.
- Web UI reachable.
- All four copper ports link and ping.
- Both SFP+ cages link.
- VLAN and management configuration work.
- 512 KB image, DIO flash.
- Default config `192.168.10.247/24`, all ports VLAN1.

## Hardware findings

### Copper port map

`regget 0x63f0` with one cable at a time:

| Physical port | Logical port | Observed |
|---|---|---|
| 1 | 4 | `0x00050000` |
| 2 | 5 | `0x00500000` |
| 3 | 6 | `0x05000000` |
| 4 | 7 | `0x50000000` |
| SFP6 | 3 | `0x00004000` |

Machine map:

```c
.log_to_phys_port = {0,0,0,6,1,2,3,4,5}
.phys_to_log_port = {4,5,6,7,8,3,0,0,0}
```

This is the REF mapping, not the NONAME reversed map.

### MDI reverse

Register `0xa90`:

| Value | Result |
|---|---|
| `0x0c` | physical 1/2 dead |
| `0x00` | physical 4 works, labels wrong |
| `0x03` | physical 1/2 and 3/4 work, Web order correct |

Final:

```c
.mdi_reverse = 0x03
```

### SFP

| Cage | Logical | SDS | GPIO | I²C |
|---|---|---|---|---|
| SFP5 | 8 | 1 | 38 | 39/40 |
| SFP6 | 3 | 0 | 37 | 41/40 |

The SFP pin variant P2 (left GPIO38, right GPIO37) was the working one.

### Flash

```text
32 Mbit SPI
DIO
flash_sio = 0
```
